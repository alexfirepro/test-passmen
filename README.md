# 👑 ROYAL NOIR | VIP Mini App для сети мужских клубов

Премиальное веб-приложение (Telegram Mini App / PWA) для сети ночных джентльменских клубов:
- 💳 **Цифровая VIP-карта гостя** с динамическим QR-кодом и штрих-кодом для считывания хостес;
- 📈 **Накопительная система уровней** (`XS` ➔ `S` ➔ `M` ➔ `L` ➔ `XL` ➔ `ROYAL VIP`), учет кэшбэка и скидок;
- 🍾 **Онлайн-бронирование столов** с выбором клуба сети, зала (Front Stage, VIP Lounge, Mezzanine, Private Suite) и предзаказом;
- 🎰 **«Колесо Искушений»**: ежедневный спин с бонусами, сгорающими к 06:00 утра (стимул прийти сегодня);
- 🏆 **Интерактивные ночные квесты**: Early Bird до 23:30, пятничные визиты, комплименты артисткам;
- 💎 **Каталог «Валюты Удовольствия» (ВУ)**: моментальный обмен накопленных баллов на приватные танцы, кальяны и элитные напитки;
- 🔒 **Конфиденциальность & Прямая линия с генеральным директором**.

## 🚀 Быстрый запуск локально

### Требования
- **Node.js** версии 18 или выше
- **npm** (идет вместе с Node.js)

### Установка и запуск:
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ВАШ_ЛОГИН/royal-noir-miniapp.git
cd royal-noir-miniapp

# 2. Установите зависимости
npm install

# 3. Запустите локальный сервер разработки
npm run dev
```

Приложение откроется по адресу: `http://localhost:3000`

## 🌐 Публикация на GitHub Pages (Бесплатный хостинг)

В проекте уже настроен автоматический деплой через **GitHub Actions** (`.github/workflows/deploy.yml`):

1. **Создайте репозиторий на GitHub** и загрузите в него проект:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Royal Noir VIP Mini App"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/royal-noir-miniapp.git
   git push -u origin main
   ```

2. **Включите GitHub Pages в настройках репозитория**:
   - Перейдите в ваш репозиторий на GitHub ➔ **Settings** (Настройки).
   - В левом меню выберите **Pages**.
   - В разделе **Build and deployment** ➔ **Source** выберите **GitHub Actions**.
   
3. **Готово!** При каждом `git push` в ветку `main` проект будет автоматически собираться и публиковаться по адресу:  
   `https://ВАШ_ЛОГИН.github.io/royal-noir-miniapp/`

## 📱 Подключение в Telegram Mini App (Web App)

Чтобы приложение открывалось прямо внутри Telegram у гостей:

1. Откройте в Telegram бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/mybots` и выберите вашего клубного бота (или создайте нового через `/newbot`).
3. Нажмите **Bot Settings** ➔ **Menu Button** ➔ **Configure menu button**.
4. Отправьте ссылку на ваше приложение (из GitHub Pages, например: `https://ВАШ_ЛОГИН.github.io/royal-noir-miniapp/`).
5. Укажите название кнопки меню, например: `👑 Кабинет гостя` или `Клубная карта`.
6. Теперь при нажатии на кнопку в диалоге с ботом у пользователя будет открываться полноэкранный личный кабинет гостя!
